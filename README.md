# Tohfa - Little things. Lasting feelings.

A responsive static frontend inspired by the GiftName mockup. It is built with plain HTML, CSS and JavaScript, so it needs no Node.js setup or build step.

## Open it locally

1. Extract the ZIP (if using the ZIP).
2. Keep `index.html` and the `assets` folder together.
3. Open `index.html` in a browser.

## What works in this prototype

- Responsive desktop and mobile layouts
- Search across sample products
- Filters for budget, recipient, vibe, occasion and handmade items
- Sorting by price and name
- Save/unsave products to a session wishlist
- Product detail popups
- Sample maker-submission and newsletter flows
- Mobile navigation

## Before a public launch

- `GiftName` is a placeholder brand name.
- Product names, images, prices, maker names, stock and delivery details are sample/illustrative. Replace them with verified items and obtain permission to use the sellers' product photos.
- The seller button is intentionally a demo notice until you have real product URLs.
- The newsletter and maker forms are frontend-only; connect them to a form service or backend before collecting real data.
- Add the final privacy, contact, terms and affiliate-disclosure pages as relevant.
- Test all pages and links on real mobile devices before publishing.

## Publish it

This can be deployed as a static site to GitHub Pages, Netlify, Vercel, or any regular web host. Upload `index.html` and the complete `assets` folder together.
